Монохромный рабочий стол на Hyprland, который ставится целиком или по частям.
Хочешь всё — бери всё; хочешь только панель — бери только её. Установщик
спрашивает, какие модули нужны, сохраняет всё, что перезаписывает, а
`uninstall.sh` возвращает твои файлы на место.

![Рабочий стол](docs/screenshots/desktop.png)

Ничего не раскрашено: палитра — чёрный, серые и белый, а состояние передаётся
яркостью, а не оттенком. Обои на снимке — одни из четырёх, которые процедурно
генерирует [hypr-lock-theme](https://github.com/Whyslab/hypr-lock-theme).

## Модули

```bash
./install.sh --list
```

| Модуль | Что ставит |
|---|---|
| `core` | `hyprland.conf` — привязки клавиш, правила окон, палитра |
| `panel` | HyprPanel с модулями CPU/RAM/диск, которые показывают, что реально грузит систему |
| `terminal` | kitty и btop в той же палитре |
| `menus` | тема rofi и меню выключения wlogout |
| `scripts` | скриншоты, переключение обоев, всплывающий btop |
| `fonts` | правила fontconfig: цветные эмодзи впереди иконочных шрифтов, верные ханьские начертания |
| `housekeeping` | еженедельный таймер очистки восстановимых кэшей |
| `wallpapers` | пустой каталог обоев и загрузчик с wallhaven |

## Установка

```bash
git clone https://github.com/Whyslab/hyprland-dotfiles.git
cd hyprland-dotfiles
./install.sh
```

Спросит, какие модули нужны. Без интерактива:

```bash
./install.sh --all
./install.sh --modules panel,terminal,menus
./install.sh --dry-run                    # показать шаги, ничего не менять
./install.sh --prefix /tmp/test           # поставить во временный каталог
```

**Ничего не перезаписывается без копии.** Каждый файл, который установщик
заменяет, сохраняется в `~/.local/share/hyprland-dotfiles/backup-<дата>/`, а
список установленного — в `installed.txt` рядом. Именно поэтому `uninstall.sh`
может вернуть твой конфиг ровно таким, каким он был.

Root не нужен нигде, и ни один пакет за тебя не ставится: установщик сообщает,
чего не хватает, и всё равно копирует конфиги — доставишь нужное потом.

### Что модулям требуется

| Модуль | Нужно |
|---|---|
| `core` | `hyprland` |
| `panel` | `hyprpanel` |
| `terminal` | `kitty`, `btop` |
| `menus` | `rofi`, `wlogout` |
| `scripts` | `grim`, `slurp`, плюс `hyprpicker` и `awww` для замороженного кадра и демона обоев |

Везде подразумевается Nerd Font — конфиги просят JetBrainsMono Nerd Font.

### Соседние репозитории

`hyprland.conf` вешает клавиши на четыре инструмента, живущих в собственных
репозиториях: каждый полезен и без этого рабочего стола.

| Клавиши | Инструмент |
|---|---|
| `SUPER + R` | [rofi-launcher](https://github.com/Whyslab/rofi-launcher) — приложения с папками и закреплёнными |
| `SUPER + SHIFT + C` | [rofi-command-center](https://github.com/Whyslab/rofi-command-center) — 200 системных команд |
| `SUPER + SHIFT + B` | [backup-manager](https://github.com/Whyslab/backup-manager) — шифрованные ночные копии |
| `SUPER + SHIFT + N` | [screen-sleep](https://github.com/Whyslab/screen-sleep) — простой, сон и ночной фильтр |
| экран блокировки | [hypr-lock-theme](https://github.com/Whyslab/hypr-lock-theme) — hyprlock и hypridle |

Пока инструмент не установлен, клавиша ничего не делает. Клонировать нужные:

```bash
./install.sh --companions rofi-launcher,screen-sleep
```

Каждый клонируется в `~/Projects/` и ставится своим `install.sh` — этот
репозиторий никогда не устанавливает другой за тебя.

Горизонтальный свайп тремя пальцами переключает рабочие столы.

## Что стоит объяснить

### Модули панели показывают, что грузит систему *сейчас*

Встроенный модуль CPU в HyprPanel даёт процент. Эта замена добавляет пять
процессов, которые реально едят процессор, посчитанных по **дельте** между
опросами — так же, как это делает btop, а не через `ps %cpu`, который
усредняет за всю жизнь процесса и потому держит в топе часами демон, который
был занят на старте.

```json
{"pct":"28","cores":"4","top":"  9.9%  firefox  690\n  5.9%  Isolated Web Co  158696"}
```

Модуль диска раскладывает цифру, которую показывает бар, потому что она не
совпадает с `df`:

```
used    = всего - доступно     ← отсюда берётся процент
data    = реально занято файлами
reserve = 5%, которые ext4 держит для root, used - data
```

Каждый модуль печатает одну строку JSON и больше ничего — поэтому их можно
взять в Waybar или любую другую панель, умеющую запускать команду.

### Скриншоты, которые не убивают тултипы

`grim -g "$(slurp)"` сначала запускает slurp, а тот накрывает экран своей
layer-shell поверхностью. Hyprland шлёт панели `wl_pointer.leave`, GTK прячет
тултип, и grim снимает бар, на котором уже ничего нет.

`screenshot.sh` меняет порядок: сначала снимает пиксели, замораживает картинку
через hyprpicker, и только потом даёт выделить область и вырезает её из снимка.
Тултип оказывается в кадре, потому что он был на экране в момент съёмки.

### btop живёт в спец-воркспейсе

btop стартует вместе с сессией, скрытым. К первому нажатию `SUPER + \`` его
графики уже полны истории, а не начинаются с пустой оси. Esc прячет окно, а не
закрывает — чтобы это оставалось верным и в следующий раз.

Привязка сделана на `code:49` — физическую клавишу под Esc, — поэтому работает
одинаково в любой раскладке.

## Обои

Каталог поставляется пустым. Картинки с машины, откуда всё это взято, в
основном скачаны с wallhaven: распространять их мы не вправе, а 85 МБ JPEG'ов в
репозитории конфигов не нужны никому.

Четыре монохромных 4K-обоины процедурно генерирует hypr-lock-theme; либо впиши
идентификаторы wallhaven и скачай:

```bash
cp wallpapers.list.example wallpapers.list
$EDITOR wallpapers.list
./fetch-wallhaven.sh
```

Ссылка выводится из идентификатора, поэтому ни ключ API, ни аккаунт не нужны.
Подробности — в [wallpapers/README.md](wallpapers/README.md).

## Чего это не умеет

- **Один монитор, один масштаб.** `screenshot.sh` пересчитывает логические
  координаты в физические, считая масштаб единым; при разных DPI обрезка уедет.
- **Заточено под Arch.** Ничего специфичного для Arch тут нет, но имена пакетов
  в документации именно оттуда, а `clean-caches.sh` чистит кэши тех программ,
  которыми пользуются на этой машине.
- **`hyprland.conf` — один файл, а не набор include'ов.** Взять из него кусок
  значит отредактировать файл, а не отключить подключение.
- **Панель — это HyprPanel.** Скрипты CPU/RAM/диск работают с любой панелью,
  умеющей запускать команду, а `config.json` и `modules.json` — нет.
- **Конфигурации дисплей-менеджера нет.** SDDM появляется только в пути к
  обоям; сама тема входа сюда не входит.

## Удаление

```bash
./uninstall.sh                # снести установленное, вернуть твои файлы
./uninstall.sh --keep-backups # снести, бэкапы не трогать
```

Работает по `installed.txt`, поэтому удаляет ровно то, что было установлено, и
ничего сверх. Твои обои и клонированные соседние репозитории в `~/Projects/`
остаются на месте.

## Разработка

```bash
bash tests/run-tests.sh
```

51 проверка, и ни одной не нужны ни сессия Hyprland, ни экран, ни root:
синтаксис shell, разбор всех поставляемых JSON и XML fontconfig, что модуль
ставит свои файлы и не ставит чужие, что ни один плейсхолдер `__HOME__` не
доживает до установленного файла, что удаление возвращает подменённые оригиналы
и при этом не трогает пользовательские обои, что каждый модуль панели печатает
одну строку валидного JSON со всеми ключами, которые подставляет бар, и что
ничего из этого не ломается в локали с запятой в качестве десятичного
разделителя.
